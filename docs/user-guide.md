# Руководство пользователя

## Назначение системы

Система предназначена для учёта:
- подразделений и кабинетов
- принтеров и МФУ
- моделей картриджей
- остатков картриджей
- заправок, установок и списаний
- отчётов и уведомлений

## Вход в систему

Открой адрес frontend, например:

```text
http://localhost:3000
```

Далее:
- введи логин и пароль
- нажми `Войти в панель`

Если сессия неактивна 30 минут, система автоматически завершит вход.

## Обзор

На главном экране доступны:
- сводка по количеству принтеров и картриджей
- быстрые показатели по статусам
- последние действия
- уведомления о нехватке

Раздел удобен для ежедневной проверки текущей ситуации.

## Отделы и кабинеты

В разделе `Отделы` можно:
- создавать подразделения
- заводить кабинеты
- просматривать статус отдела и кабинета
- выводить их из использования без физического удаления

Если отдел или кабинет уже выведен из использования, система не даст привязывать к ним новые активные сущности.

## Принтеры

В разделе `Принтеры` можно:
- создать принтер или МФУ
- указать отдел и кабинет
- задать модель, IP, серийный номер и статус
- настроить слоты картриджей
- вывести принтер из эксплуатации

Система проверяет совместимость модели принтера и модели картриджа прямо при сохранении.

## Картриджи

Основные операции:
- приход на склад
- приход в резерв
- установка в принтер
- снятие с принтера
- отправка на заправку
- возврат с заправки
- списание
- ручная корректировка количества

Статусы картриджей:
- `На складе`
- `Резерв`
- `Установлен`
- `На заправке`
- `Списан`

## Модели картриджей

Для модели картриджа можно указать:
- название
- бренд
- тип
- минимальный остаток
- совместимые модели принтеров

Каталог моделей поддерживает:
- поиск
- фильтрацию
- пагинацию

## Журнал действий

Если роль пользователя разрешает доступ к журналу, можно смотреть:
- входы в систему
- операции по картриджам
- изменения пользователей
- изменения принтеров
- действия с отделами и кабинетами

Для удобства есть:
- поиск
- фильтры
- просмотр старых и новых значений

## Отчёты

В разделе отчётов доступны:
- расход за период
- остатки по отделам
- остатки по кабинетам
- остатки по моделям
- остатки по типам
- остатки по моделям принтеров
- списки по состояниям: склад, резерв, заправка, списание

Экспорт поддерживается в:
- `Excel`
- `PDF`

## Уведомления

Система показывает предупреждения, если остаток по модели падает до порога.

Порог задаётся администратором или пользователем с соответствующим правом.

## Если что-то не получается

Проверь:
- не истекла ли сессия
- хватает ли прав на нужный раздел
- выбран ли активный отдел и кабинет
- совместима ли модель картриджа с выбранным принтером

Если проблема остаётся, передай администратору:
- что именно делал пользователь
- текст ошибки
- примерное время ошибки
